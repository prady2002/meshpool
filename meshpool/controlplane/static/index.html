🧠 Run a model

Run a real LLM across the pool. Models too big for one machine shard across nodes; models that fit are replicated so requests load-balance for throughput — with automatic failover if a machine drops.

Upload a trained checkpoint (.npz) — it's staged in the pool and each node runs only its slice of layers, so weights too big for one machine still run across the pool.

📦 Store files

Drop a file into the pool — it's replicated across your machines' spare disk, so it survives any single machine going away, and you can download it from anywhere on the mesh.
